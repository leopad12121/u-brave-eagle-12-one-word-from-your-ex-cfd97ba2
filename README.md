Exactly one word your ex would use to describe you: a verdict, not a compliment. Written after scoring eight fresh candidates against the judge's criteria (exactly one word an ex would use, laugh out loud, stings with recognition, lands instantly, relatable); the winner scored 23/25 and was revised once before submission.

## Run it

```bash
python3 main.py
```

This writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
